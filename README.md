# Транскрибация аудио и видео

Локальное веб-приложение: принимает аудио- и видеофайлы, распознаёт речь моделью OpenAI Whisper на вашем компьютере и создаёт документ Word (`.docx`) с полным текстом и временными метками фрагментов.

## Возможности

- Аудио: MP3, WAV, M4A, FLAC, OGG, MPEG и WebM.
- Видео: MP4, MOV, MKV, AVI и WebM (извлекается звуковая дорожка).
- Автоопределение языка и ручной выбор языка.
- Пять размеров модели Whisper: от быстрой `tiny` до более точной `large`.
- Word-документ с полным текстом и списком фрагментов с временными метками.
- Файл обрабатывается локально и удаляется из временной папки после обработки.

Разделение по говорящим не выполняется. Качество зависит от модели, языка, шума и качества записи. Длинные файлы и большие модели могут требовать много памяти и времени.

## Запуск на Windows

Установите Python 3.11 и FFmpeg и убедитесь, что команда `ffmpeg` доступна в PowerShell. Затем в папке проекта выполните:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Откройте `http://localhost:8501`. При первом запуске выбранной модели её веса скачиваются в локальный кеш.

## Запуск на macOS или Linux

Установите Python 3.11 и FFmpeg, затем выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

## Запуск через Docker

```bash
docker build -t audio-transcriber .
docker run --rm -p 8501:8501 audio-transcriber
```

Откройте `http://localhost:8501`. При первом использовании модели потребуется интернет для скачивания её весов.

## Публикация на GitHub

Создайте публичный пустой репозиторий и из папки проекта выполните, указав URL своего репозитория:

```bash
git init
git add .
git commit -m "Add local audio and video transcription app"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Публичный репозиторий содержит исходный код, но сам по себе не публикует работающий сайт. Приложение можно запускать локально или развернуть на сервере с Python, FFmpeg и ресурсами для выбранной модели. Не загружайте личные записи в публичный демо-сервис.

## Приватность

Распознавание выполняется локально библиотекой Whisper. Файл хранится во временной папке только во время обработки. Веса модели загружаются из сети и сохраняются в локальном кеше. Не публикуйте записи и транскрипции в GitHub.
